# SoM 人类玩家精简客户端

参考「网游脱机挂」的极简画面系统，为人类玩家打造的 SoM（Source of Mana）精简客户端。
与 AI 无头客户端共用同一套协议层（`som_protocol.py`），但多了一个看得见的窗口。

## 体积对比

| | 完整 Web 客户端 | AI 无头客户端 | 人类精简客户端 |
|---|---|---|---|
| **客户端文件** | 140 MB | 15 KB | 56 KB |
| **协议层** | 内置 | som_protocol.py（56 KB） | som_protocol.py（56 KB） |
| **内存占用** | 400+ MB（浏览器） | 25 MB | 60 MB |
| **依赖** | 浏览器 + wasm 运行时 | Python 3.8+ | Python 3.8+ / tkinter |
| **渲染** | GPU/Canvas | 无 | CPU（tkinter Canvas） |
| **音频** | 需要 | 无 | 无 |
| **操作** | 键鼠 | AgentBridge | 键鼠 + 点击 |

## 快速开始

### 1. 安装依赖

```bash
pip install websockets
# tkinter 通常随 Python 自带；若缺失：
#   Debian/Ubuntu: apt install python3-tk
#   Alpine: apk add py3-tkinter
```

### 2. 启动客户端

```bash
python3 lite_human_client.py ws://your-server:27012/ws \
    --account 你的账号 \
    --password 你的密码 \
    --nick "你的角色名" \
    --auto-create
```

首次使用可以只填服务器地址，在登录窗口里输入账号密码，勾选
「自动注册账号 / 创建角色」后点「连接」。

**参数说明：**

| 参数 | 环境变量 | 说明 |
|---|---|---|
| `url`（位置参数） | `SOM_WS_URL` | SoM 服务器 WebSocket 地址 |
| `--account` | `SOM_ACCOUNT` | 账号名 |
| `--password` | `SOM_PASSWORD` | 密码 |
| `--nick` | `SOM_NICK` | 角色昵称（留空则用账号名） |
| `--auto-create` | `SOM_AUTO_CREATE=1` | 账号/角色不存在时自动创建 |
| `--auto-play` | `SOM_AUTO_PLAY=1` | 进游戏后立即开启自动挂机 |
| `--debug` | — | 输出调试日志 |

### 3. 操作

| 操作 | 效果 |
|---|---|
| 左键点空地 | 移动到该坐标（本地预测 + 服务器确认） |
| 左键点 NPC / 怪物 | 选中目标并攻击 |
| 左键点掉落物 | 走过去并拾取 |
| 左键点玩家 | 选中该玩家 |
| 右键点空地 | 移动（不选中任何目标） |
| `W A S D` / 方向键 | 持续行走 |
| 鼠标滚轮 | 缩放视图（35%–250%） |
| 鼠标滚轮（右侧面板上） | 滚动右侧信息面板 |
| 工具栏 `+` / `−` | 缩放视图 |
| 工具栏 `截图` | 保存当前画面 |
| 工具栏 `AI竞技场` | 打开（可选的）AI 竞技场窗口 |
| 工具栏 `断开` | 断开与服务器的连接 |
| 聊天框输入 `/xxx` | 作为命令发给服务器（如 `/arena status`） |

## 正常游戏流程

客户端启动后**直接进入正常游戏世界**，不会自动进入任何竞技场。
推荐的上手流程：

1. **找长老对话**：走到村子里的长老（Elder）身边，左键点他选为目标，
   再点右侧「交互」（或点画面上的他）。会弹出对话窗口：
   - 只有文字时点「继续」；
   - 出现选项时点其中一个选项（比如「I will help.」）；
   - 对话结束后点「关闭」。
2. **装备小刀**：新角色上线时背包里会自带一把 **Short Sword（小刀）**。
   在右侧「装备 / 背包」里选中它，点「装备」（或双击），
   武器格就会变成 `武器: Short Sword`，同时背包里的数量减一。
   装备栏共 8 格：头 / 颈 / 胸 / 手 / 武器 / 盾 / 腿 / 脚，
   点已装备的格子即可卸下。
3. **打怪**：左键点一只怪物（Maggot / Piou）即可选中并攻击，
   右侧「目标」面板有「攻击 / 拾取 / 交互 / 复活 / 喝药」按钮，
   也可以直接按键盘移动靠近后自动攻击。
   击杀后会有经验、掉落物（黄色菱形）与伤害统计。

> 提示：装备武器的攻击加成由服务器计算，**必须真的把刀装备上**才有效果。
> 如果点击「装备」后武器格仍是空的，说明服务器缺少物品表
> （`SOM_ITEMS_JSON`），见下面的「服务器要求」。

## AI 竞技场（可选）

AI 竞技场是**可选项**，默认关闭，不影响正常游戏：

- 工具栏上的 `AI竞技场: 未开启` 按钮显示当前状态；
- 点它打开窗口，选择场地模板后点「开始」：
  - `tutorial_maggot` —— 教学：3 杀 / 60 秒
  - `grind_maggot` —— 刷怪：5 杀 / 120 秒
- 窗口里的「状态」会显示击杀进度、死亡数与经验；
- 点「停止」随时结束，竞技场怪物会被清除。

竞技场由服务器在**你自己角色周围**生成怪物，只在当前这台服务器上有效。
也可以直接在聊天框输入 `/arena start tutorial_maggot`、`/arena status`、
`/arena stop` 来控制（效果一样）。

### 视图元素

- **网格**：100 px 细格 / 500 px 粗格，原点在画面中心时显示坐标轴。
- **相机**：平滑跟随角色（lerp 0.18），进游戏或换地图时自动回中。
- **血条**：实体头顶，绿色为友方、红色为敌方。
- **目标高亮**：当前选中目标带白色虚线描边。
- **特效**：点击移动标记（X）、伤害飘字（白色普通 / 橙色暴击 / 灰色闪避）、
  攻击连线，均带颜色渐变淡出。
- **死亡实体**：显示为灰色扁平椭圆。

### 自动挂机

勾选「自动打怪 / 自动拾取 / 自动喝药」后点「应用挂机设置」：

- **自动打怪**：寻找最近的敌对 NPC（`friendly=False`），移动至攻击距离后
  循环释放技能。
- **自动拾取**：寻找最近的掉落物，移动到 24 px 内后拾取。
- **自动喝药**：HP 低于阈值（默认 30%）时自动使用背包里的药水。

再点「停止全部挂机」可随时终止。

## 服务器要求

- 服务器必须是本仓库 `goserver/` 目录下编译的 Go 服务器
  （完整 Web 客户端连接的官方 Godot 服务器没有对应的 RPC 实现）。
- **物品表**：服务器启动时需要 `SOM_ITEMS_JSON` 指向 `tools/export/items.json`
  （或在工作目录下放一份 `items.json`）。没有它，服务器只认识内置的
  测试物品（1001–1006），`Short Sword`（3056796356）等真实物品
  将无法装备，点击「装备」不会有任何反应。
- **可选的竞技场命令**：较新的服务器支持 `/arena start|status|stop`
  （在 `arena.go` 中实现）。老服务器会把 `/arena` 当成未知命令，
  不影响客户端其余功能。

## 技术细节

### 协议层

与 AI 客户端共用 `som_protocol.py`：

- Godot 4 SceneMultiplayer 二进制 RPC 协议，WebSocket 传输。
- Variant 编解码：BOOL / INT（2-bit 压缩）/ FLOAT / STRING / STRING_NAME /
  VECTOR2 / DICTIONARY / ARRAY / PACKED_STRING_ARRAY / NIL。
- RPC name ID = `sources/network/Network.gd` 中 119 个 `@rpc` 方法排序后的下标。
  本客户端用到的补充项：`TriggerCommand=93`、`TriggerInteract=96`、
  `TriggerChoice=91`、`TriggerNextContext=97`、`TriggerCloseContext=92`。
- 实体身份：`agentRID == CharID`，正数为玩家、负数为 NPC/怪物；
  `PreloadEntity` 用正 RID 表示种子 NPC（charID 取负），
  竞技场怪物则直接用负 charID。客户端用 `friendly` 字段区分敌我。
- 装备：服务器推 `ItemEquiped` / `RefreshEquipment`，客户端维护
  `world.equipment`（8 格）与 `world.inventory`（物品 ID → 数量）。

### 线程模型

- **主线程**：tkinter 事件循环，负责全部 UI 绘制与交互。
- **后台线程**：asyncio 事件循环，负责 WebSocket 收发与自动挂机逻辑。
- **桥接**：UI 通过 `queue.Queue` 向后台提交指令；后台通过
  `world.emit` → `ui_queue` 把世界事件推给 UI 线程，
  `Application._tick()` 每 50 ms 拉取一次并刷新画面。

### 移动预测

SoM 的移动是客户端权威的：服务器不会把移动者的位置广播回来。
客户端以 120 px/s 本地推算自身位置，收到服务器位置时再校正，
因此点击移动在弱网下也不会「卡顿回弹」。
